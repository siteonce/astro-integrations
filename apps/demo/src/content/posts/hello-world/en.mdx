# Hello world

This is the first sample post in the `@siteonce/astro-intl` demo. It gives the listing, the post route, the tag pages, the sitemap, and the RSS feed something to render in both locales.

Each post is a folder with one file per locale (`src/content/posts/<id>/en.mdx` and `de.mdx`). The co-located `feat.png` keeps the demo offline.
